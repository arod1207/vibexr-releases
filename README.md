# VibeXR

VibeXR lets you run a team of AI coding agents from a virtual office on your Meta Quest. This repo holds the
downloads for the **VibeXR desktop app**, which runs on your Mac and connects your headset to your code.

## Download

Get the latest `.dmg` from [Releases](https://github.com/arod1207/vibexr-releases/releases/latest) (Mac with Apple Silicon).

1. Open the `.dmg` and drag **VibeXR** into **Applications**.
2. First time only: right-click **VibeXR** in Applications → **Open** → **Open** (the beta isn't signed by Apple yet).
3. VibeXR lives in the menu bar. Set up your repos and AI tools, then pair your headset.

VibeXR tells you when a new version is available.
